# Ruta de Inteligencia Artificial

Curso de Machine Learning, Deep Learning e IA Generativa con Jupyter Notebooks. Se publica un capítulo por semana.

Sitio: https://bsycruz.github.io/riwi_IA/

<a href="https://github.com/RiwiAI"><img src="_static/riwi_ai_logo.png" alt="Logo de Riwi AI" width="64" align="left"></a>

Organización: [Riwi AI](https://github.com/RiwiAI), cursos intensivos de IA.

<br clear="left">

## Contenido

| Pilar | Módulos |
|-------|---------|
| [Machine Learning](01_machine_learning/) | Base analítica y diagnóstico visual, motor de ajuste, supervisados / no supervisados / refuerzo, optimización y producción |
| [Deep Learning](02_deep_learning/) | Redes neuronales, visión por computador, secuencias y transformers, entrenamiento y despliegue |
| [IA Generativa](03_ia_generativa/) | Modelos generativos, prompts y APIs de LLMs, RAG, agentes en producción |
| [Documentación](04_documentacion/) | Lecturas recomendadas por pilar |

Los notebooks de cada capítulo se pueden abrir en Google Colab o Kaggle desde el sitio.

## Ejecutar en local

Necesitas Node.js.

```bash
npm install -g mystmd
myst start
```

Para correr los notebooks: `pip install -r requirements.txt`.
