Python no trae de serie todo lo que necesita un proyecto de datos: lo potente está en sus
**librerías**. En este capítulo conocemos las que usaremos durante todo el curso y para qué sirve
cada una.

## Objetivos de aprendizaje

- Identificar las librerías clave del ecosistema de datos en Python y su función.
- Instalar e importar librerías en un notebook.
- Elegir la librería adecuada según la tarea: cálculo, tablas, gráficos o modelos.
